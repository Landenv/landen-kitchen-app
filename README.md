# Landen Kitchen

Бесплатное приложение для Android: меню для всей семьи, список покупок и пошаговая готовка.
Без рекламы и регистрации. Все данные о семье хранятся только на вашем телефоне.

## Скачать

**[landen-kitchen-1.0.0.apk](https://github.com/Landenv/landen-kitchen-app/raw/main/landen-kitchen-1.0.0.apk)** — версия 1.0.0, 51,7 МБ, Android 7.0 и новее.

Скачивайте приложение только по этой ссылке. Файл из других источников может быть изменён посторонними.

## Как установить

1. Нажмите на ссылку выше и скачайте файл.
2. Откройте скачанный файл. Телефон попросит разрешить установку из этого источника (браузера или
   «Файлов») — разрешите.
3. Если появится предупреждение Play Protect о незнакомом приложении, нажмите «Подробнее» → «Всё равно
   установить». Так бывает со всеми приложениями не из Google Play.

## Что умеет

- Семья: возраст, рост, вес, активность, аллергии и нелюбимые продукты — приложение рассчитает калории.
- План питания на период до 14 дней под ваш бюджет, замена любого блюда.
- Более 110 рецептов восьми кухонь и свои рецепты.
- Список покупок по отделам, запасы дома, отправка списка в мессенджер.
- Пошаговая готовка с таймерами, напоминания о покупках и разморозке.
- Копия данных в файл, светлая и тёмная тема.

Расчёт калорий ориентировочный и не заменяет консультацию врача. Возрастная маркировка: 0+.
